Important (Windows):
1. WhatsApp Desktop app must be installed — this launches the app directly, not WhatsApp Web
2. The first time Chrome will show a popup asking "Open WhatsApp?" — check "Always allow" so it stops asking
3. Chrome only allows a webpage to launch an external app once per real click — it silently blocks any automatic/timed attempts after that as an anti-abuse measure. So instead of auto-looping, click "Send Next" for each contact — every click is a real click, so the app opens every time, no skips
4. Each click pops the app to that contact's chat with your message pre-filled — you still tap Send inside WhatsApp
